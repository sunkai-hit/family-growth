# 同频 · 家庭成长工作台

通过 ChatGPT 交流，GitHub 归档，经 Cloudflare Pages + D1 呈现的在线亲子成长工作台。

- 在线访问：Cloudflare Pages（首次需连接 GitHub 仓库）
- 数据归档：仓库内的 `public/data/workbench.json`
- 可查询数据：Cloudflare D1，数据库 `family-growth-db`
- 对话入口：继续使用 ChatGPT；同步需要主动触发或专门的定时任务。

**请勿提交账号密码、API Token 或不准备公开的家庭信息。**

详细部署说明与代码将随初始项目一同补充。
